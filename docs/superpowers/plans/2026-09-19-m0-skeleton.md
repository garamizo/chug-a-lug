# M0 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running skeleton: PocketBase and SvelteKit on the home box, phone-number OTP signup and PIN login, reachable at https://chugalug.app and https://pb.chugalug.app through a Cloudflare Tunnel, with nightly backups.

**Architecture:** Three Compose services (`web` SvelteKit Node adapter, `pocketbase` single binary with JS hooks and migrations, `cloudflared` tunnel). PocketBase owns users, auth, and data; a PocketBase hook calls Twilio Verify for OTP and mints auth tokens; the browser talks to PocketBase directly on its own hostname. Local development runs the PocketBase binary and `vite dev` natively, no Docker.

**Tech Stack:** PocketBase v0.40.4 (Go binary, JS hooks via goja), SvelteKit 2 + Svelte 5 + TypeScript, `pocketbase` JS SDK, `@sveltejs/adapter-node`, `@vite-pwa/sveltekit`, Vitest, Playwright, Docker Compose, cloudflared, Twilio Verify v2, `just` task runner.

**Spec:** `docs/superpowers/specs/2026-09-19-chugalug-design.md` (sections 2, 4, 12, 13, 14). Product scope and UI labels: `README.md`.

## Global Constraints

- PocketBase version pinned to **v0.40.4** everywhere (Dockerfile, local download script).
- Node **22 LTS**. Package manager npm. TypeScript strict.
- Phone numbers stored as **E.164** (`+13125551234`). Only US numbers accepted in M0.
- `users.phone` is the only password-auth identity field; password field `min: 4`; auth token duration **15552000** seconds (180 days).
- The OTP dev bypass works only when PocketBase runs with `--dev` **and** `OTP_DEV_CODE` is set.
- Secrets live only in `.env` (git-ignored) and `.secrets/` (git-ignored). Never commit them.
- Public hostnames: `chugalug.app` → web:3000, `pb.chugalug.app` → pocketbase:8090.
- Developer terms in code and docs; UI strings come from `web/src/lib/labels.ts` only.
- Commit after every task with a conventional message. Do not push unless asked.
- Timezone for anything user-facing: `America/Chicago`.

```bash
#!/usr/bin/env bash
# Downloads the pinned PocketBase binary for local development into pocketbase/pocketbase.
set -euo pipefail
PB_VERSION="0.40.4"
ARCH="$(uname -m)"
case "$ARCH" in
  x86_64) PB_ARCH="amd64" ;;
  aarch64|arm64) PB_ARCH="arm64" ;;
  *) echo "unsupported arch $ARCH" >&2; exit 1 ;;
esac
cd "$(dirname "$0")/../pocketbase"
if [ -x ./pocketbase ] && ./pocketbase --version | grep -q "$PB_VERSION"; then
  echo "pocketbase $PB_VERSION already present"; exit 0
fi
URL="https://github.com/pocketbase/pocketbase/releases/download/v${PB_VERSION}/pocketbase_${PB_VERSION}_linux_${PB_ARCH}.zip"
tmp="$(mktemp -d)"
curl -fsSL "$URL" -o "$tmp/pb.zip"
unzip -oq "$tmp/pb.zip" pocketbase -d .
chmod +x ./pocketbase
rm -rf "$tmp"
./pocketbase --version
```

```bash
  --migrationsDir pocketbase/pb_migrations --hooksDir pocketbase/pb_hooks)
if [ "$BG" = "--background" ]; then

    sleep 0.5
  done
  echo "pocketbase did not become healthy" >&2; cat "$DATA_DIR/pocketbase.log" >&2; exit 1
```

```js
migrate((app) => {
  const users = app.findCollectionByNameOrId("users")

  users.fields.add(new TextField({ name: "phone", required: true, min: 8, max: 16, pattern: "^\\+1[0-9]{10}$" }))
  users.fields.add(new BoolField({ name: "is_admin" }))
  users.fields.add(new BoolField({ name: "share_position" }))
  users.fields.add(new TextField({ name: "home_station", max: 32 }))
  users.fields.add(new BoolField({ name: "left_early" }))

  users.indexes.push("CREATE UNIQUE INDEX idx_users_phone ON users (phone)")

  users.passwordAuth.enabled = true
  users.passwordAuth.identityFields = ["phone"]
  users.fields.getByName("password").min = 4
  users.authToken.duration = 15552000 // 180 days

  users.listRule = "@request.auth.id != ''"
  users.viewRule = "@request.auth.id != ''"
  users.createRule = null // only superusers and hooks create users
  users.updateRule = "id = @request.auth.id && @request.body.is_admin:isset = false"
  users.deleteRule = null

  app.save(users)
}, (app) => {
  const users = app.findCollectionByNameOrId("users")
  for (const f of ["phone", "is_admin", "share_position", "home_station", "left_early"]) {
    users.fields.removeByName(f)
  }
  users.indexes = users.indexes.filter((i) => !i.includes("idx_users_phone"))
  users.passwordAuth.identityFields = ["email"]
  users.fields.getByName("password").min = 8
  users.authToken.duration = 604800
```

```js
// Normalizes a US phone number to E.164. Returns null when it cannot.
module.exports = function normalizePhone(input) {
  if (typeof input !== "string") return null
  const digits = input.replace(/\D/g, "")
  if (digits.length === 10) return "+1" + digits
  if (digits.length === 11 && digits[0] === "1") return "+" + digits
  return null
}
```

- [ ] **Step 2: Write `pocketbase/pb_hooks/otp.pb.js`**

```js
/// <reference path="../pb_data/types.d.ts" />

// POST /api/crawl/otp/start  {phone}
routerAdd("POST", "/api/crawl/otp/start", (e) => {
  const normalizePhone = require(`${__hooks}/phone.js`)
  const body = e.requestInfo().body
  const phone = normalizePhone(body.phone)
  if (!phone) return e.json(400, { message: "Enter a 10-digit US phone number." })

  let allowed = null
  try { allowed = $app.findFirstRecordByData("allowlist", "phone", phone) } catch (_) {}
  if (!allowed) return e.json(403, { message: "This number is not on the crew list. Ask the admin." })

  // rate limit: 5 starts per phone per hour, shared across hook VMs via the app store
  const key = "otp_starts:" + phone
  const now = Math.floor(Date.now() / 1000)
  const starts = ($app.store().get(key) || []).filter((t) => now - t < 3600)
  if (starts.length >= 5) return e.json(429, { message: "Too many codes requested. Try again in an hour." })
  starts.push(now)
  $app.store().set(key, starts)

  const devCode = $os.getenv("OTP_DEV_CODE")
  if ($app.isDev() && devCode) {
    console.log("[otp] dev mode: code for", phone, "is", devCode)
    return e.noContent(204)
  }

  const sid = $os.getenv("TWILIO_ACCOUNT_SID"), tok = $os.getenv("TWILIO_AUTH_TOKEN"), vsid = $os.getenv("TWILIO_VERIFY_SID")
  if (!sid || !tok || !vsid) return e.json(502, { message: "SMS is not configured on the server." })
  // Go's http client turns URL userinfo into a Basic Authorization header.
  const res = $http.send({
    url: `https://${sid}:${tok}@verify.twilio.com/v2/Services/${vsid}/Verifications`,
    method: "POST",
    body: "To=" + encodeURIComponent(phone) + "&Channel=sms",
    headers: { "content-type": "application/x-www-form-urlencoded" },
    timeout: 20,
  })
  if (res.statusCode >= 300) {
    console.log("[otp] twilio start failed", res.statusCode, JSON.stringify(res.json))
    return e.json(502, { message: "Could not send the code. Try again in a minute." })
  }
  return e.noContent(204)
})

// POST /api/crawl/otp/check  {phone, code, pin}
routerAdd("POST", "/api/crawl/otp/check", (e) => {
  const normalizePhone = require(`${__hooks}/phone.js`)
  const body = e.requestInfo().body
  const phone = normalizePhone(body.phone)
  const code = String(body.code || "").trim()
  const pin = String(body.pin || "")
  if (!phone) return e.json(400, { message: "Enter a 10-digit US phone number." })
  if (!/^[0-9]{4,8}$/.test(pin)) return e.json(400, { message: "PIN must be 4 to 8 digits." })
  if (!/^[0-9]{4,8}$/.test(code)) return e.json(400, { message: "Enter the code from the text message." })

  let allowed = null
  try { allowed = $app.findFirstRecordByData("allowlist", "phone", phone) } catch (_) {}
  if (!allowed) return e.json(403, { message: "This number is not on the crew list. Ask the admin." })

  const devCode = $os.getenv("OTP_DEV_CODE")
  let approved = false
  if ($app.isDev() && devCode) {
    approved = code === devCode
  } else {
    const sid = $os.getenv("TWILIO_ACCOUNT_SID"), tok = $os.getenv("TWILIO_AUTH_TOKEN"), vsid = $os.getenv("TWILIO_VERIFY_SID")
    if (!sid || !tok || !vsid) return e.json(502, { message: "SMS is not configured on the server." })
    const res = $http.send({
      url: `https://${sid}:${tok}@verify.twilio.com/v2/Services/${vsid}/VerificationChecks`,
      method: "POST",
      body: "To=" + encodeURIComponent(phone) + "&Code=" + encodeURIComponent(code),
      headers: { "content-type": "application/x-www-form-urlencoded" },
      timeout: 20,
    })
    approved = res.statusCode < 300 && res.json && res.json.status === "approved"
  }
  if (!approved) return e.json(401, { message: "That code did not match." })

  let user = null
  try { user = $app.findFirstRecordByData("users", "phone", phone) } catch (_) {}
  if (!user) {
    const users = $app.findCollectionByNameOrId("users")
    user = new Record(users)
    user.set("phone", phone)
    user.set("name", allowed.get("name"))
    user.set("is_admin", !!allowed.get("is_admin"))
    user.set("verified", true)
  }
  user.setPassword(pin)
  $app.save(user)

  return e.json(200, { token: user.newAuthToken(), record: user })
})
```

- [ ] **Step 4: Write the hook test helpers `web/tests/hooks/setup.ts`**

```ts
export const PB = process.env.PB_URL ?? 'http://127.0.0.1:8090';
const ADMIN_EMAIL = process.env.PB_ADMIN_EMAIL ?? 'admin@chugalug.app';
const ADMIN_PASSWORD = process.env.PB_ADMIN_PASSWORD ?? 'change-me-please';

export async function superuserToken(): Promise<string> {
  const r = await fetch(`${PB}/api/collections/_superusers/auth-with-password`, {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify({ identity: ADMIN_EMAIL, password: ADMIN_PASSWORD })
  });
  if (!r.ok) throw new Error(`superuser login failed: ${r.status}`);
  return (await r.json()).token as string;
}

export async function seedAllowlist(phone: string, name: string, isAdmin = false): Promise<void> {
  const token = await superuserToken();
  const existing = await fetch(`${PB}/api/collections/allowlist/records?filter=${encodeURIComponent(`phone="${phone}"`)}`, {
    headers: { Authorization: token }
  }).then((r) => r.json());
  if (existing.totalItems > 0) return;
  const r = await fetch(`${PB}/api/collections/allowlist/records`, {
    method: 'POST',
    headers: { 'content-type': 'application/json', Authorization: token },
    body: JSON.stringify({ phone, name, is_admin: isAdmin })
  });
  if (!r.ok) throw new Error(`seed failed: ${r.status} ${await r.text()}`);
}

export async function deleteUser(phone: string): Promise<void> {
  const token = await superuserToken();
  const list = await fetch(`${PB}/api/collections/users/records?filter=${encodeURIComponent(`phone="${phone}"`)}`, {
    headers: { Authorization: token }
  }).then((r) => r.json());
  for (const u of list.items ?? []) {
    await fetch(`${PB}/api/collections/users/records/${u.id}`, { method: 'DELETE', headers: { Authorization: token } });
  }
}

export function post(path: string, body: unknown, token?: string) {
  return fetch(`${PB}${path}`, {
    method: 'POST',
    headers: { 'content-type': 'application/json', ...(token ? { Authorization: token } : {}) },
    body: JSON.stringify(body)
  });
}
```

```ts
/** Normalizes a US phone number to E.164, or returns null. Mirrors pocketbase/pb_hooks/phone.js. */
export function normalizePhone(input: string): string | null {
  const digits = (input ?? '').replace(/\D/g, '');
  if (digits.length === 10) return `+1${digits}`;
  if (digits.length === 11 && digits.startsWith('1')) return `+${digits}`;
  return null;
}
```

```ts
import PocketBase, { type RecordModel } from 'pocketbase';
import { writable } from 'svelte/store';
import { PUBLIC_PB_URL } from '$env/static/public';

export type UserRecord = RecordModel & {
  phone: string;
  name: string;
  is_admin: boolean;
  share_position: boolean;
  home_station: string;
  left_early: boolean;
};

export const pb = new PocketBase(PUBLIC_PB_URL);
pb.autoCancellation(false);

export const auth = writable<{ user: UserRecord | null }>({
  user: pb.authStore.isValid ? (pb.authStore.record as UserRecord) : null
});

pb.authStore.onChange(() => {
  auth.set({ user: pb.authStore.isValid ? (pb.authStore.record as UserRecord) : null });
});

export async function startOtp(phone: string): Promise<void> {
  await pb.send('/api/crawl/otp/start', { method: 'POST', body: { phone } });
}

export async function checkOtp(phone: string, code: string, pin: string): Promise<void> {
  const res = await pb.send('/api/crawl/otp/check', { method: 'POST', body: { phone, code, pin } });
  pb.authStore.save(res.token, res.record);
}

export async function loginWithPin(phone: string, pin: string): Promise<void> {
  await pb.collection('users').authWithPassword(phone, pin);
}

export function logout(): void {
  pb.authStore.clear();
}
```

- [ ] **Step 2: `scripts/backup.sh`**

```bash
#!/usr/bin/env bash
# Copies the whole data/ directory (SQLite, uploads, PocketBase backups) to BACKUP_DIR with a timestamp.
# Run from cron on the host, e.g. "30 4 * * * cd /path/to/chug-a-lug && just backup".
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
cd "$ROOT"
set -a; [ -f .env ] && . ./.env; set +a
DEST="${BACKUP_DIR:-./data/backups}/snapshot-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$DEST"
# Trigger a consistent PocketBase backup first, then copy everything.
if curl -fs http://127.0.0.1:8090/api/health >/dev/null; then
  TOKEN=$(curl -s -X POST http://127.0.0.1:8090/api/collections/_superusers/auth-with-password \
    -H 'content-type: application/json' \
    -d "{\"identity\":\"$PB_ADMIN_EMAIL\",\"password\":\"$PB_ADMIN_PASSWORD\"}" | python3 -c 'import sys,json;print(json.load(sys.stdin)["token"])')
  curl -fs -X POST http://127.0.0.1:8090/api/backups -H "Authorization: $TOKEN" -H 'content-type: application/json' -d '{}' >/dev/null
fi
rsync -a --exclude 'backups/snapshot-*' data/ "$DEST/"
echo "backup written to $DEST"
ls -1dt "${BACKUP_DIR:-./data/backups}"/snapshot-* | tail -n +8 | xargs -r rm -rf   # keep 7 snapshots
```

```markdown
# Operations

## Where things live
- Home box: `~/chug-a-lug`, Docker Compose services `pocketbase`, `web`, `cloudflared`.
- Data: `data/pb_data` (SQLite + uploads), `data/pb_data/backups` (PocketBase zips), `data/backups/snapshot-*` (host copies).
- Secrets: `.env` (never committed). Metra token file in `.secrets/`.
- Dashboards: Cloudflare Zero Trust → Tunnels → `chugalug`; Twilio Console → Verify → `Chugalug`; PocketBase admin at http://127.0.0.1:8090/_/ from the box.

## Daily
- `just logs` to tail everything. `docker compose ps` should show three services `Up` and pocketbase `healthy`.
- Backups run inside PocketBase at 04:00 and `just backup` from host cron at 04:30.

## Add a crew member
PocketBase admin → Collections → `allowlist` → New record: phone in E.164 (`+13125550100`), name, `is_admin` if needed.
They then open https://chugalug.app/login → Join → text code → PIN.

## Reset someone's PIN
They use Join again with the same number; the new PIN replaces the old one. No admin action needed.

## Deploy a change

    git pull
    just up            # docker compose up -d --build
    docker compose logs -f web

Migrations apply automatically when the `pocketbase` container starts.

## Restore from backup
1. `docker compose down`
2. Either unzip a `pb_backup_*.zip` into a fresh `data/pb_data/`, or `rsync -a data/backups/snapshot-<ts>/ data/`
3. `docker compose up -d`

## Disaster fallback (home internet or power is out on event day)
1. On any Linux VPS: install Docker, `git clone` the repo, copy `.env` and the latest `data/backups/snapshot-*` over.
2. `just up`. The same tunnel token moves with `.env`; Cloudflare routes to whichever `cloudflared` is connected.
3. Total time is about 15 minutes; rehearse once before December.

## Rotate a secret
Edit `.env`, then `docker compose up -d --force-recreate <service>`. Twilio and Metra tokens are read at request time by the hooks; the Cloudflare token needs a cloudflared restart.
```
