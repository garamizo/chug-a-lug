# Run Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every route boards at Aurora by default and ends with a computed "Run home" leg back to its Board at
station; Live counts down to that train, shows a riding-home state, and ends the crawl at its arrival.

**Architecture:** The run home is a `legs` row with `to_stop = ''`, produced by `recomputeLegs` exactly like the
existing opening leg (`from_stop = ''`). A new pure `crawlEnd()` in `current.ts` is the single answer to "when is
the crew home". Consumers (current, strip, cohesion, board, ItineraryView) learn to read a closing leg.

**Tech Stack:** SvelteKit (Svelte 5), TypeScript, Vitest, Playwright, PocketBase JS hooks + migrations.

**Spec:** `docs/superpowers/specs/2026-11-15-ride-home-design.md`

## Global Constraints

- Nothing plans legs except `computeLegs`/`recomputeLegs` (preview, commit, recompute share it).
- User-visible strings only in `web/src/lib/labels.ts`; README glossary row for **Run home**.
- Home station: `{ id: 'AURORA', name: 'Aurora' }`.
- The `itineraries` create hook does **not** default `start_station`; the planner's create and clone do.
- Closing leg arriving at or past service minute 1440 is `impossible`.
- `crawlEnd` with an impossible closing leg returns `{ at: null, reason: 'no_run_home' }` and never yields `after`.
- Completion uses the closing leg's scheduled `arrive_at`.
- Tests first. Each task ends green: `cd web && npm test && npm run check`; tasks touching hooks also run
  `bash scripts/test-hooks.sh`; the final task runs `npm run test:e2e` too. One test run at a time (fixed ports).
- Stage explicit paths; never `git add -A`.

## Review Focus

1. **Last stop checked in late, recompute not landed yet** → must stay `override`, not jump to `after` from
   stale legs (Task 3 test `late terminal check-in with stale legs stays override`).
2. **Last bar is at Aurora itself** → closing leg is a 0-minute walk; no ride-home board state, crawl ends at
   ready time + walk (Task 1 `same-station run home`, Task 4 `no rideHome for a walk`).
3. **Route with zero stops but a Board at** → no closing leg, no crash (Task 1 `no stops, no legs`).
4. **Practice day** → riding state and `after` work off the projected plan clock like any other leg
   (Task 4 `rideHome on a practice day`).
5. **Draft cleared Board at through the API** → 400 `start_station_required` (Task 2 hooks test).

### Task 3: `crawlEnd` and the crawl's position (`current.ts`, `strip.ts`)

**Files:**
- Modify: `web/src/lib/live/current.ts`, `web/src/lib/live/strip.ts`
- Test: `web/tests/unit/current.test.ts`, `web/tests/unit/strip.test.ts`

**Interfaces:**
- Produces:
  ```ts
  export type CrawlEnd = { at: Date; reason?: undefined } | { at: null; reason: 'no_run_home' };
  export function closingLeg(stops: Stop[], legs: Leg[]): Leg | null; // from_stop = last stop id, to_stop = ''
  export function crawlEnd(stops: Stop[], legs: Leg[], startAt: Date): CrawlEnd;
  /** True when the closing leg was planned from this check-in: its ready_at is within 60 s of
   *  check-in + last.dwell_min. Always true with no anchor or an anchor at another stop. */
  export function closingFresh(stops: Stop[], legs: Leg[], anchor: { stopId: string; at: string } | null): boolean;
  ```
  (Codex plan review: `ready_at >= checkedIn` is not evidence; a 20:30 check-in against a stale 21:00 ready time
  would pass. The exact `check-in + dwell` match is what `recomputeLegs` produces from that anchor.)
  `crawlEnd`: closing leg resolved → its `arrive_at`; closing leg `impossible` → `{ at: null, reason }`; no closing
  leg → today's end (last stop's departure if any, else its arrival); no stops → `{ at: startAt }`.

- [ ] **Step 1: Failing tests** (current.test.ts):

    equals the closing leg's `depart_at`.
  - `still at the last stop while riding home`: now between closing depart and arrive → `source 'clock'`, stop = last.
  - `after only once home`: now ≥ closing `arrive_at` → `'after'`; one minute before → `'clock'`.
  - `an impossible run home never ends the crawl`: closing `kind 'impossible'`, now far later → `'clock'`;
